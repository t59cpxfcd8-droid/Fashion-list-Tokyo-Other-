# Fashion Press Tokyo / Other Brand Overview Scraper

Fashion Press のコレクション一覧から、選択した場所に表示されているブランド分だけブランド概要を取得するGUIツールです。

## 取得対象

- 対象サイト: https://www.fashion-press.net/collections/
- 場所: 東京・その他からGUIで選択
- 範囲: 選択した各シーズン・場所の一覧1ページ目に表示されているブランドのみ
- 次ページ巡回: なし

## CSV列

```text
ブランド, ブランド（カタカナ）, ブランドURL, ブランド概要
```

## 実行方法

Macでは `FashionPressScraper.command` をダブルクリックすると起動できます。

初回起動時に「Macに損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした」と表示される場合があります。

その場合は、ファイルを右クリックして `開く` を選び、確認画面でもう一度 `開く` を押してください。

それでも開けない場合は、`システム設定` → `プライバシーとセキュリティ` を開き、ブロックされたアプリの項目で `このまま開く` を選択してください。

これはGitHubからダウンロードした未署名ファイルに対するmacOSの標準警告です。配布元が信頼できる場合のみ開いてください。

ターミナルから実行する場合:

```bash
python3 fashion_press_collections_scraper.py
```

## お客様PCに必要なもの

- Python 3: 必要
- VS Code: 実行だけなら不要。コードを編集する場合のみあると便利

Macの場合、Windowsの `.bat` の代わりに `.command` ファイルを使います。

## サーバー負荷対策

- 一覧ページ取得ごとに5秒待機
- ブランド詳細ページ取得ごとに6秒待機
- 失敗時は待機してから最大3回まで再試行
- 同じブランドURLは重複取得しない
- 各シーズンの1ページ目だけを対象にして、ページ巡回を行わない

## 履歴管理

取得済みブランドは `fashion_press_history.db` に保存されます。

次回以降は以下の情報を完全一致で確認し、履歴にあるブランドは取得しません。

- Fashion Press のブランド詳細ページURL
- ブランド名
- ブランド（カタカナ）
- 公式サイトURL

過去にこのツールで出力したCSVが `output/` にある場合は、起動時に履歴DBへ自動取り込みします。

## 出力先

CSVはスクリプトと同じ階層の `output/` フォルダに保存されます。
